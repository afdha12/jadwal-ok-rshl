# Aplikasi Jadwal Operasi

Aplikasi Jadwal Operasi adalah sebuah sistem yang digunakan untuk mengelola jadwal operasi di rumah sakit. Aplikasi ini memungkinkan pengguna untuk menambahkan, mengedit, dan menghapus jadwal operasi, serta menampilkan jam operasi yang tersedia berdasarkan tanggal dan ruang operasi.

## Fitur

- **Tambah Jadwal Operasi**: Pengguna dapat menambahkan jadwal operasi baru dengan mengisi informasi seperti tanggal operasi, jam operasi, nama pasien, usia, dokter, ruang operasi, dan lain-lain.
- **Edit Jadwal Operasi**: Pengguna dapat mengedit jadwal operasi yang sudah ada.
- **Hapus Jadwal Operasi**: Pengguna dapat menghapus jadwal operasi yang sudah tidak diperlukan.
- **Filter Jadwal Operasi**: Pengguna dapat memfilter jadwal operasi berdasarkan tanggal dan ruang operasi.
- **Tampilkan Jam Operasi Tersedia**: Aplikasi menampilkan jam operasi yang tersedia berdasarkan tanggal dan ruang operasi yang dipilih.
